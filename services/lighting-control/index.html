Lighting Control

One crew. One schedule.

Good lighting is designed with the room, not added after. We lay out fixtures, run the circuits, install the dimming panels and program scenes, so one button sets the whole space.

What's included

  • Lighting layout and fixture selection
  • Recessed, track and cove lighting
  • Dimming panels and keypads
  • Scenes, schedules and app control
  • Landscape and step lighting
  • Art and gallery lighting
  • Integration with shades and AV
  • Programming and fine-tuning
