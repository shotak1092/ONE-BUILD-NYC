# One Build NYC — website

Static site. Pages are generated by `_build/build.py` (edit content there, run `python3 _build/build.py`, commit).
Hosted on Netlify; the contact form uses Netlify Forms.

## Blog posts from BabyLoveGrowth

1. Approve the article in BabyLoveGrowth (keep auto-publish off).
2. Edit it: NYC/NJ only, no partner company names, real project details, links to /services/ and /areas/ pages.
3. Save as `_build/posts/<url-slug>.md` using the front matter in `_build/posts/_TEMPLATE.md` (title, description, date, hero photo name, services). Leave out `draft: true` to publish.
4. Run `python3 _build/build.py`, commit, push. The post gets the site's hero, related services, BlogPosting schema, a blog card and a sitemap entry.
